# Asakiri course schemas

Machine-readable JSON Schemas for the Asakiri course format, version 1. These
define the on-disk shape of a course so anyone can build editors, validators,
or learner applications against it. The format is specified in
[../docs/COURSE-FORMAT.md](../docs/COURSE-FORMAT.md).
